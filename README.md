# Lokesh Portfolio

This is a React portfolio for J Lokesh Manikanth Reddy.

## Covers the assignment requirements

- React Router based portfolio
- `NavLink` navigation
- `HashRouter` for GitHub Pages deployment
- Home page with about me, research interests, personal details, and profile visual
- Projects page with multiple projects

## Scripts

- `npm start`
- `npm run build`
- `npm test`
- `npm run deploy`

## Before deployment

Update the `homepage` value in `package.json` with your real GitHub username and add the missing project repository links if you have them.
